# Center Line Handling Implementation

## Overview
The center line handling system will detect the center line, rotate to face it, and center the robot on it for accurate navigation between the dropoff and pickup locations.

## Implementation Details

### Detect Center Line
```python
def detect_center_line(object_detector, frame):
    """
    Detect the center line in the frame.
    
    Args:
        object_detector: YOLO object detector instance
        frame: Camera frame
        
    Returns:
        Detection data for the center line, or None if not detected
    """
    if frame is None:
        return None
    
    # Run YOLO detection
    detections, _ = object_detector.get_detections(frame)
    
    # Get detection for the center line
    center_line_detection = object_detector.get_best_detection("center_line", detections)
    
    return center_line_detection
```

### Rotate to Face Center Line
```python
def rotate_to_face_center_line(robot_controller, detection):
    """
    Rotate the robot to face the detected center line.
    
    Args:
        robot_controller: Robot controller instance
        detection: Center line detection data
        
    Returns:
        True if the robot is facing the center line, False otherwise
    """
    if detection is None:
        return False
    
    x1, y1, x2, y2 = detection["box"]
    box_center_x = (x1 + x2) / 2
    camera_center_x = 320  # Assuming camera width is 640px
    
    # Calculate how far off-center the line is
    error_x = camera_center_x - box_center_x
    
    # If the error is small, the robot is facing the center line
    if abs(error_x) < 20:
        return True
    
    # Calculate rotation speed based on error
    z_vel = np.clip(-error_x * 0.05, -15, 15)
    
    # Rotate to face the center line
    robot_controller.ep_robot.chassis.move(
        x=0, y=0, z=z_vel, xy_speed=0.3
    ).wait_for_completed()
    
    return False
```

### Intermediary Centering Step
```python
def center_on_line(robot_controller, object_detector):
    """
    Center the robot on the center line by translating laterally.
    
    Args:
        robot_controller: Robot controller instance
        object_detector: YOLO object detector instance
        
    Returns:
        True if the robot is centered on the line, False otherwise
    """
    # First, rotate to 270 degrees (facing down)
    current_x, current_y, current_heading = robot_controller.get_position()
    target_heading = 270  # degrees
    
    # Convert current heading to degrees
    current_heading_deg = np.rad2deg(current_heading)
    
    # Calculate angle difference
    angle_diff = (target_heading - current_heading_deg) % 360
    if angle_diff > 180:
        angle_diff -= 360
    
    # Rotate to face down
    if abs(angle_diff) > 5:
        robot_controller.ep_robot.chassis.move(
            x=0, y=0, z=angle_diff, xy_speed=0.3
        ).wait_for_completed()
    
    # Get current frame
    frame = robot_controller.get_frame()
    if frame is None:
        return False
    
    # Detect the center line
    center_line_detection = detect_center_line(object_detector, frame)
    
    # If the center line is not visible, we can't center on it
    if center_line_detection is None:
        return False
    
    # Calculate the center of the center line
    x1, _, x2, _ = center_line_detection["box"]
    box_center_x = (x1 + x2) / 2
    camera_center_x = 320  # Assuming camera width is 640px
    
    # Calculate how far off-center the line is
    error_x = camera_center_x - box_center_x
    
    # If the error is small, the robot is centered on the line
    if abs(error_x) < 10:
        # Stop the robot
        robot_controller.ep_robot.chassis.drive_speed(x=0, y=0, z=0)
        return True
    
    # Calculate lateral movement speed based on error
    y_vel = np.clip(error_x * 0.001, -0.1, 0.1)
    
    # Translate laterally to center on the line
    robot_controller.ep_robot.chassis.drive_speed(x=0, y=y_vel, z=0)
    
    return False
```

### Save Target Coordinate Position
```python
def save_target_coordinate(robot_controller):
    """
    Save the current position as a target coordinate for future navigation.
    
    Args:
        robot_controller: Robot controller instance
        
    Returns:
        (x, y) coordinate position
    """
    current_x, current_y, _ = robot_controller.get_position()
    return (current_x, current_y)
```

### Center Line Handling Loop (Pre-Waypoint)
```python
def center_line_pre_waypoint_loop(robot_controller, object_detector):
    """
    Main center line handling loop for pre-waypoint.
    
    Args:
        robot_controller: Robot controller instance
        object_detector: YOLO object detector instance
        
    Returns:
        (True, target_position) if successful, (False, None) otherwise
    """
    # Get current frame
    frame = robot_controller.get_frame()
    if frame is None:
        return False, None
    
    # Detect the center line
    center_line_detection = detect_center_line(object_detector, frame)
    
    # If the center line is not visible, we need to search for it
    if center_line_detection is None:
        # Rotate in place to search for the center line
        robot_controller.ep_robot.chassis.move(
            x=0, y=0, z=15, xy_speed=0.3
        ).wait_for_completed()
        return False, None
    
    # Try to face the center line
    is_facing = rotate_to_face_center_line(robot_controller, center_line_detection)
    
    # If the robot is facing the center line, perform the centering step
    if is_facing:
        is_centered = center_on_line(robot_controller, object_detector)
        
        # If the robot is centered on the line, save the target position
        if is_centered:
            target_position = save_target_coordinate(robot_controller)
            return True, target_position
    
    return False, None
```

### Center Line Handling Loop (Post-Waypoint)
```python
def center_line_post_waypoint_loop(robot_controller, object_detector, target_position):
    """
    Main center line handling loop for post-waypoint.
    
    Args:
        robot_controller: Robot controller instance
        object_detector: YOLO object detector instance
        target_position: Target position to return to
        
    Returns:
        True if successful, False otherwise
    """
    # Calculate distance to target position
    current_x, current_y, _ = robot_controller.get_position()
    target_x, target_y = target_position
    
    distance = np.sqrt((target_x - current_x)**2 + (target_y - current_y)**2)
    
    # If we're close enough to the target position, perform the centering step
    if distance < 0.5:
        is_centered = center_on_line(robot_controller, object_detector)
        
        # If the robot is centered on the line, we're done
        if is_centered:
            return True
    else:
        # Move toward the target position
        # First, calculate the angle to the target
        angle = np.arctan2(target_y - current_y, target_x - current_x)
        angle_deg = np.rad2deg(angle)
        
        # Rotate to face the target
        current_heading_deg = np.rad2deg(robot_controller.get_position()[2])
        angle_diff = (angle_deg - current_heading_deg) % 360
        if angle_diff > 180:
            angle_diff -= 360
        
        if abs(angle_diff) > 5:
            robot_controller.ep_robot.chassis.move(
                x=0, y=0, z=angle_diff, xy_speed=0.3
            ).wait_for_completed()
        
        # Move toward the target
        move_distance = min(distance, 0.5)
        robot_controller.ep_robot.chassis.move(
            x=move_distance, y=0, z=0, xy_speed=0.3
        ).wait_for_completed()
    
    return False
```

## Integration with State Machine
The center line handling system will be integrated into multiple states in the state machine:
1. Path Planning (2: center line pre-waypoint)
2. Intermediary centering step
3. Path Planning (4: center line post-dropoff)
4. Path Planning (5: center line post-intermediary centering)
