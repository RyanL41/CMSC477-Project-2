Localization: 
- We know that the robot will start at (2, -2).
- We know that we will see at least one AprilTag at the start of the match.
- We can use the AprilTag to localize the robot.
- If no AprilTag is detected, we will rotate in place to try to find an AprilTag.

- We will keep track of all the AprilTags that we see, in a hash table by the ID of the AprilTag.

Path Planning:
- Instead of using Dijkstra's algorithm, we will do the following:
    - We will set a target label (YOLO object) and a target coordinate position. 
    - Always rotate the robot to face the target coordinate position.
    - The robot will try to move to the target coordinate position until it sees the target label.
    - It is assumed that the target label will be visible at some point between the robot and the 
      target coordinate position.
    - If the robot cannot see the target label, it will rotate in place to try to find the target label.
    - If the robot spots another April Tag, it will add it to the hash table. 
    - If the robot gets too close to an April Tag (<1 box unit):
        - If the april tag is on the left of the robot, it will drive right.
        - If the april tag is on the right of the robot, it will drive left.
    - If the robot detects another robot (label "robot"):
        - If the robot is on the left of the robot, it will drive right.
        - If the robot is on the right of the robot, it will drive left.

Lego Pickup:
    - The robot will identify the bounding box of the lego block it has detected.
    - The robot will rotate such that the lego block is centered in the frame
    - The robot will move forward until the y-position of the lego block falls under a threshold of 230
    - The robot will lower the arm, close the gripper and pick up the arm
    - If the robot gets too close to an April Tag (<1 box unit):
        - If the april tag is on the left of the robot, it will drive right.
        - If the april tag is on the right of the robot, it will drive left.
    - If the robot detects another robot (label "robot"):
        - If the robot is on the left of the robot, it will drive right.
        - If the robot is on the right of the robot, it will drive left.



State Machine: 
- We will use the following states:
    - Localization: 
        - The robot will find an april tag, store the position of the april tag, and calculate its own
        position relative to the april tag.
        - Once this is successful, it will transition to the first Path Planning state.
    - Path Planning (1: lego block):
        - The target labels will be the set ["lego_big", "lego_med", "lego_small"].
        - The target coordinate position will be (10, -4).
        - The path planning rules from above apply. 
        - Once the robot sees the target label, it will transition to the lego pickup state.
    - Lego Pickup:
        - the lego-pickup rules from above apply
        - Once the robot has picked up the lego block, it will transition to the second path planning state.
    - Path Planning (2: center line pre-waypoint):
        - The target labels will be the set ["center_line"].
        - The target coordinate position will be (6, -3).
        - The path planning rules from above apply.
        - Once the robot reaches the target coordinate position, it will rotate until:
            - it sees the center line
            - it is facing the center line
        - Once this is successful, it will transition to the third path planning state.
    - Intermediary centering step:
        - The robot will rotate to 270 degrees.
        - The robot will translate laterally until it is centered on the center line.
        - The robot will save the target coordinate position
        - Once this is successful, it will transition to the fourth path planning state.
    - Path Planning (3: center line post-waypoint):
        - The target labels will be the set ["closet"].
        - The target coordinate position will be (current_x, current_y + 15)  # save for later
        - The path planning rules from above apply.
        - Once the robot sees the target label, it will transition to the lego dropoff state.
    - Lego Dropoff:
        - The robot will center towards the closet
        - The robot will move forwards until the closet is undetected
        - The robot will lower the arm, open the gripper and raise the arm
        - Once this is successful, it will transition to the fifth path planning state.
    - Path Planning (4: center line post-dropoff):
        - The target labels will be the set ["center_line"].
        - The target coordinate position will be the saved target coordinate position from Path Planning (3)
        - The path planning rules from above apply.
        - Once the robot reaches the target coordinate position, it will rotate until:
            - it sees the center line
            - it is facing the center line
        - Once this is successful, it will transition to the sixth path planning state.
    - Path Planning (5: center line post-intermediary centering):
        - The target labels will be the set ["center_line"].
        - The target coordinate position will be the saved target coordinate position from the Intermediary centering step
        - The path planning rules from above apply.
        - Once the robot reaches the target coordinate position, it will rotate until:
            - it sees the center line
            - it is facing the center line
        - Once this is successful, it will transition back to the first path planning state.
